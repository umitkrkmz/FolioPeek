# Güvenlik Politikası / Security Policy

## Desteklenen sürümler / Supported versions

Yalnızca Microsoft Store'daki en güncel sürüm desteklenir. / Only the latest version on the Microsoft Store is supported.

## Güvenlik açığı bildirimi / Reporting a vulnerability

FolioPeek internete hiç bağlanmayan (`internetClient` yetkisi olmayan) yerel bir PDF uygulamasıdır. Bir güvenlik açığı bulursanız (ör. bozuk bir PDF'te beklenmeyen davranış, karartılan içeriğin dosyada kalması, şifreleme ya da yerel depolama hatası), lütfen herkese açık bir Issue açmadan önce GitHub'ın **Private vulnerability reporting** (özel güvenlik bildirimi) özelliğiyle bildirin.

FolioPeek is a local PDF app that never goes online (no `internetClient` capability). If you find a security issue (for example unexpected behaviour on a malformed PDF, redacted content left in a file, or an encryption or local storage problem), please report it privately with GitHub's **Private vulnerability reporting** before opening a public issue.
